## 下载使用
将步骤简化到三岁小孩都能完成的程序，有问题和不理解欢迎iuuse

从 Releases 下载 `pipeRun.exe`。
运行环境、界面、字体均内置，不需要 Python、Java、Node、WebView2 或代理软件，不在线下载依赖。
仍需电脑版微信、本人登录和正常网络；证书及临时代理授权须自己确认。

1. 添加账号，学号必须与小程序一致。
2. 先点「获取账号」，完成授权。倒计时出现后，在「数体智慧体育」小程序内登录一次。
   这一步是最难的，要先在软件内启动第二步，然后再去电脑端微信打开乐跑小程序，记住要实现一次登录，如果已经登录
   可以在小程序里面退出登录重新登录。
4. 等凭证保存和网络恢复后，点「检查账号」。只读检查不上传、欢迎提交。
5. 仅在获许可测试范围内核对生成模板及账号后确认；两项确认默认不勾。
6. 查看结果。结果不明先到官方小程序核查。

教程可从「F1 说明 / 设置 → 快速上手」重新打开。支持鼠标、1–5、上下、Enter、Tab、Esc。
重新获取登录后检查、提交、查看的完成状态刷新，但当天防重复尝试账本不会清除。
